# Dados

## `raw`

Respostas brutas ou amostras públicas necessárias para rastreabilidade.

## `processed`

Dados tratados produzidos pelo sistema.

Não versionar documentos sigilosos, dados pessoais desnecessários ou arquivos recebidos sem autorização. Arquivos grandes devem ser mantidos fora do Git quando não forem essenciais ao desenvolvimento.
